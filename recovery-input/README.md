# Transfers and corrections after 23 September 2026

Upload your original PDF or CSV files here using GitHub's Add file > Upload files.
Keep the originals; do not edit phone_count_data.json or the live Firebase payload.

Use names such as 2026-09-24_warehouse-to-maynooth.csv.
Include the transfer date/time, source shop, destination shop, model,
IMEI or serial number, quantity, and a transfer/reference ID where available.
For sales, returns or corrections, include the action type and original reference.

Once the files are uploaded, ask Codex to reconcile them against the
23 September inventory. Reconciliation must deduplicate references and IMEIs,
report conflicts and show the proposed changes before modifying live inventory.

This folder is in the private phone-count repository. Do not include passwords
or service-account credentials in uploaded files.
